# 🌦️ 날씨 웹앱 만들기 — 4일 프로젝트 가이드 (학생용)

## 우리가 만들 것

실시간 날씨 API(Open-Meteo)를 연동한 **나만의 날씨 웹앱**입니다.

- **홈 화면**: 하늘 사진 히어로 + 도시 검색 + 주요 도시 8곳의 현재 날씨 + 오늘의 전국 최고/최저
- **상세 화면**: 도시를 클릭하면 → 현재 날씨(기온/체감/습도/풍속/강수확률/일출일몰) + 5일 예보 + 시간별 날씨 탭
- 날씨에 따라 **배경색이 자동으로 바뀌고**, 모바일부터 큰 모니터까지 대응하는 반응형

사용 기술: **HTML / CSS / JavaScript / jQuery** — 지금까지 수업에서 배운 것들만 씁니다.
진행 방식: 강사님 코드를 **따라 입력(클론 코딩)**하되, 색상·폰트·사이트 이름·도시 목록은 **각자 다르게** 만듭니다.

## 에러가 났을 때 — 강사님 부르기 전 3단계

1. **F12 → Console 탭**: 빨간 에러가 있나요?
   - `$ is not defined` → jQuery CDN `<script>` 주소 오타
   - `Uncaught SyntaxError` → 괄호/따옴표/쉼표 빠짐 (에러 옆 줄번호 클릭)
2. **에러는 없는데 화면이 안 바뀜** → 십중팔구 **선택자 오타**. HTML의 `id="..."`와 JS의 `$('#...')` 철자가 완전히 같은지 확인 (대소문자도!)
3. **Network 탭**: API 요청이 빨간색이면 인터넷/주소 문제. 요청 클릭 → Response에서 실제 응답 확인

그래도 안 되면 손 들기! (10분 이상 혼자 붙잡고 있지 않기)

## 나만의 앱 만들기 — 커스터마이징 포인트 (4일차)

클론 코딩이어도 아래만 바꾸면 완전히 다른 앱이 됩니다. 1일차 기획서에 미리 정해두세요.

1. **사이트 이름 & 컨셉** — "오늘 뭐 입지?" 대신 나만의 이름 (예: 우산 챙겨!, 하늘 일기, 나들이 GO)
2. **색상 팔레트** — CSS `:root` 변수 몇 줄만 바꾸면 전체 색이 바뀜 (3색 원칙 지키기!)
3. **폰트** — Google Fonts에서 골라 교체 (최대 2종)
4. **홈 도시 8곳** — 내가 아는 도시들로 (좌표 목록 참고, 목록에 없으면 강사님께)
5. **날씨 아이콘/문구** — `icons/` 폴더의 SVG를 다른 스타일(라인형 등)이나 직접 그린 그림으로 갈아끼우기(파일명만 맞추면 코드 수정 없음), `getWeatherInfo()`의 문구를 내 스타일로 (예: 비 → "우산 필수! ☔")
6. **히어로 배경 사진** — 나만의 하늘/풍경 사진으로
