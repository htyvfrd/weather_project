## 홈 화면 표시 도시 (HOME_CITIES)

홈 화면에는 위 20곳 중 8곳을 골라 표시합니다. 데모 기본값은 아래와 같고, **각자 원하는 도시 8곳으로 바꾸는 것이 커스터마이징 포인트**입니다(단, 고른 도시가 반드시 `FALLBACK_CITIES` 목록에 있어야 함).

```js
// 홈 화면에 표시할 주요 도시 (FALLBACK_CITIES 중 8곳 선정)
var HOME_CITIES = ['서울', '부산', '대구', '인천', '광주', '대전', '제주', '강릉'];
```

## 세계 주요 도시 (WORLD_CITIES) — 선택 기능용

세계 도시 섹션(⭐선택 기능)을 만들 때 복붙하세요. 다른 해외 도시로 바꿔도 됩니다.

## 학생 안내 팁

- 홈에 표시할 도시 8곳(`HOME_CITIES`)은 각자 다르게 골라보세요 — 내가 사는 곳, 가고 싶은 곳 등.
- 목록에 없는 도시는 검색창에서 조회할 수 있습니다. 해외 도시는 영문명으로 검색하면 Geocoding API가 대체로 잘 찾습니다(예: `Tokyo`, `Paris`).
- 위도·경도는 시청/중심가 기준 근사값이라 프로젝트 목적(옷차림 추천, 여행 등)에는 충분히 정확합니다.
